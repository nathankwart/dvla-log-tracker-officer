Prompt 2: Security Agency (Police MTTD) Mobile Application

You are a senior Flutter engineer building an official inspection tool for Ghanaian security agencies.

Objective

Build a Flutter mobile application for Security Agencies (e.g., Police MTTD) to digitally verify DV vehicle movement records by scanning QR codes generated by the driver application and retrieving trip logs from Firebase.

Core Features
1. Secure Authentication

Implement Firebase Authentication for security personnel.

Only authenticated officers can scan QR codes and access vehicle logs.

Officers must have read-only access to trip logs.

2. QR Code Scanning

Integrate a fast and reliable QR code scanner.

Upon scanning:

Decode the vehicle identifier.

Fetch all associated trip logs from Firebase.

3. Trip Log Retrieval & Display

Display retrieved logs in a clean, readable format showing:

Date

Reason for journey

Time of leaving

Time of return

Route taken

Description of vehicle

Registration number

Driver’s name

Signature of person making entry

Include:

Chronological ordering of logs

Clear separation between trips

Quick-scroll support for inspections

4. User Interface

Minimal, professional UI optimized for roadside checks

Large text, clear labels, and fast loading

Indicate if:

No logs exist

Logs are incomplete

Vehicle data is invalid

Technical Requirements

Frontend: Flutter

Backend: Firebase

Firestore → Read-only access to trip data

Firebase Authentication → Officer login

Use the same Firestore schema as the Driver App.

Enforce strict Firestore security rules:

Officers can read but not write or modify data.

Deliverables

Complete Flutter project source code.

Firebase configuration guide (shared or separate project).

Brief report describing:

Security model

QR code scanning flow

Data access controls
